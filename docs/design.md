# 《迷惘》规则设计

> 不盈一握之迷惘，由此孕育出邪念，爬过旷野，翻越山丘，播撒灾厄于长空。

一个关于传染病怎样传播、又怎样被拦住的策略游戏。两方：**攻方**是病原体，**守方**是防控。一个人玩时另一方是电脑，
也可以两个人各执一方。一步是一天。这份说明是规则的依据：`games/miwang/sim` 实现它，数值都在配置里（`config.rules`、
性状表、科技表），改数值不用改规则代码。

## 一局是怎么回事

- 开局时某个地区出现十来个感染者，头一个月源头还会每天再送来一个（不会纯靠运气自己熄灭）。
  攻方看得到真实的感染，守方只看得到**上报**的病例和死亡——而且一种没见过的病要攒够一小簇病例才认得出来，
  守方得到第一份报告时它多半已经不止在一个地方了。
- 攻方靠感染扩大拿到**变异点**，用它换性状：传得更广、更隐蔽、更致命。
- 守方靠各地区的经济拿到**预算**，用它在各地区开措施、做研究：检测、隔离、封锁、管控口岸，直到做出疫苗。
- **攻方赢**：累计死亡达到全世界人口的一定比例（“灾厄线”，默认 1.5%）。
- **守方赢**：病原体被清除（任何地方都没有潜伏者和发病者），或者撑到期限（默认 4 年）没让攻方达成。
- 两边的拉扯：病得越重越容易被发现、病人也走不远；太温和又杀不到灾厄线。攻方通常先隐蔽地铺开、再变得致命；
  守方要在看不清的时候判断往哪里花钱，而每一项强硬措施都在消耗经济和公众信任。

## 地区

世界地图上的 176 个国家和地区，每个有：

| 属性     | 取值                  | 来源                     | 影响                                           |
| -------- | --------------------- | ------------------------ | ---------------------------------------------- |
| 人口     | 人数                  | Natural Earth            | 一切的基数                                     |
| 气候     | 热带 / 温带 / 寒带    | 按中心的纬度分           | 各传播途径在这里的强弱、季节                   |
| 富裕程度 | 0–3（低收入到高收入） | Natural Earth 的收入分组 | 医疗（病死率、发现率）、卫生条件、疫苗接种速度 |
| 密度     | 0–2                   | 人口 ÷ 面积              | 飞沫和接触传播的强弱                           |
| 经济     | 占世界的份额          | Natural Earth 的 GDP     | 守方从这里得到的预算；封锁它的代价             |
| 半球     | 南 / 北               | 纬度                     | 季节的相位                                     |

地区之间三种路线：**陆路**（真实的相邻关系）、**航线**、**海运**。后两种不是真实的航班数据，是按“两头的人口和经济、
中间的距离”用引力模型算出来的（构建地图时算好写进素材，运行时只是查表）。沿海与否由边界数据判断。

## 疾病在一个地区里怎样发展

每个地区的人分成：易感、潜伏、发病、康复、免疫（接种得到）、死亡。每天：

1. **感染**：易感者被感染的概率取决于本地的发病者（和一部分潜伏者，如果病原体能在症状出现前传播）以及
   **本地传播强度**——各条传播途径的强度，乘上这个地区对该途径的适宜程度，再乘上措施打的折扣。
2. **发病**：潜伏者按潜伏期转为发病者；其中一部分被**发现**。发现的病例要这个地区“认出了这种病”才算上报：
   全世界都还不知道有它的时候，要零星发现十例才认得出来；别处报过之后有了戒心，三例就够；做完病原鉴定
   有了检测手段，一例就认得出。认出来的那天，之前零星发现的一起算进上报。
3. **结局**：发病者按病程康复或死亡。病死率 = 病原体的致死性 × 当地医疗能挽回的比例（富裕地区更高，
   病人太多时医疗被挤兑，挽回的比例下降）× 药物的效果。
4. **外出**：潜伏者和还走得动的发病者沿三种路线把感染带到别处。

传播途径和它们各自看重的条件：

| 途径       | 适宜的条件               | 克制它的措施                                   |
| ---------- | ------------------------ | ---------------------------------------------- |
| 飞沫与空气 | 密度高、冬季、寒冷       | 口罩与距离、封锁                               |
| 接触       | 密度高                   | 封锁、隔离                                     |
| 水源与食物 | 卫生条件差（富裕程度低） | 净水与消毒                                     |
| 蚊媒       | 热带；温带只在夏季       | 灭蚊                                           |
| 血液与体液 | 医疗条件差               | 几乎不受封锁影响，靠检测与隔离                 |
| 动物宿主   | ——                       | 让疾病在已经清除的地方重新冒出来，溯源之后减弱 |

## 攻方：病原体

**变异点**：开局给的够换一条传播途径（开局就有一个选择）；之后每天有一点固定的，再加上新增感染
（开方计，越往后越慢）、波及新的地区、死亡带来的，以及短期任务和抉择给的。每换一个性状，之后的性状都贵一点。

性状分三组，都由数据表定义（前置关系 + 一组效果值）：

- **传播途径**：上表六种，各有几级。
- **症状**：从咳嗽、发热到肺炎、出血、器官衰竭。症状提高传染性、严重度、致死性——严重度越高越容易被发现，
  病人也越走不远。
- **能力**：耐寒、耐热、耐药（削弱药物和医疗）、抗原漂移（拖慢疫苗、让康复者重新变得易感）、
  延长潜伏、症状前传播、隐匿（更难发现）。

效果值是一组固定的键（`Effects`）：`air contact water vector blood animal`（各途径强度）、`severity`、
`lethality`、`stealth`、`cold`、`heat`、`resistance`、`drift`、`presymptomatic`、`incubation`、
`duration`、`aviation`、`maritime`。病原体当前的数值 = 病原体档案的底数 + 已有性状的效果之和。

不同的**病原体档案**有不同的底数和性状价格（阶段 2 用常见传染病的公开资料来填）。

**退化**：已有的性状可以退掉，拿回它底价的一半；之后的性状也跟着便宜（价格看已有几个）。别的性状还靠它当
前置时退不掉。症状太重引来了注意、或者换错了路线时用。

**技能**（花变异点、有冷却的主动操作；用了只有攻方自己知道）：

| 技能 | 作用                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 外溢 | 在一个还没到过的地区凭空落脚（不管它和别处通不通）：绕开口岸的那道防线 |
| 激增 | 一个到过的地区在两周里传得更快                                         |
| 蛰伏 | 一个月里更难被发现，代价是传得慢一些：上报少了，守方的注意力会挪开     |

## 守方：防控

**预算**每天来自各地区的经济；被封锁、停飞、封港的地区贡献变少。措施按天收维持费，人口越多越贵。
应急的钱是出了事才拨的：头一个地区上报之前只有开局那一笔，之后才按天进账——所以一开始要在研究和措施之间
掂量，铺得太开、维持费超过收入，预算见底之后所有措施的效果都会打折。

**地区措施**（每个地区单独安排；每项分三档——轻、中、全力，下表说的是全力时）：

| 措施         | 作用                             | 代价           |
| ------------ | -------------------------------- | -------------- |
| 加强检测     | 发现率提高                       | 低             |
| 隔离病例     | 按发现率压低传播                 | 低             |
| 口罩与距离   | 压低飞沫传播                     | 低，少量信任   |
| 封锁         | 大幅压低飞沫和接触传播，进出大减 | 高：经济、信任 |
| 关闭陆路口岸 | 切断陆路                         | 中             |
| 停飞         | 切断航线                         | 中，经济       |
| 封港         | 切断海运                         | 中，经济       |
| 净水与消毒   | 压低水源传播                     | 中             |
| 灭蚊         | 压低蚊媒传播                     | 中             |
| 入境筛查     | 拦下一部分输入的感染者           | 低             |

轻的那一档花全力的三成、有全力四成半的效果，中档花六成、有七成半的效果：钱不够把一个地方管到最严时，
可以把轻的措施铺开。往上加档要预付几天维持费，往下撤不要钱。界面上有成套的**预案**（监测、缓解、围堵、全撤，
和自己存的一套），也能把一个地区的做法原样**推广**到相邻的、有病例的或者全部地区（一条命令改很多地区，从
病例最重的开始，预算用完为止）。

**应急队**（全局，三支）：派到一个地区要走几天，到了以后那里的发现率提高、医疗没能挽回的病人再挽回一部分。
措施是铺开的，应急队是集中的——放在哪里是守方每隔几天就要重新想的事。队伍的位置是公开的。

**疫苗分配**：量产以后先给谁——不偏向、重灾区优先、医疗弱的优先、经济重的优先。一天能打的总量大致不变，
变的是分给谁。

**发布会**：花预算换一截公众信任，开过之后要隔一个月。

**公众信任**（0–1，全局）：措施的实际效果 = 名义效果 × 配合程度，配合程度跟着信任走。长期封锁、死亡增多、谣言
让信任下降；风险沟通、取得进展让它回升。

**研究**（全局，同时最多两项，花预算、要时间）：病原鉴定（之后才看得到对手的性状）、快速检测、流行病学调查、
治疗药物、溯源、风险沟通、国际援助（把穷地区的医疗和检测往上拉）、疫苗（候选 → 临床试验 → 量产，三步）。
疫苗量产后各地区按富裕程度逐日接种，易感者变成免疫者。抗原漂移会把疫苗的每一步拖长。

## 事件

每天有小概率发生一件事，双方都会在新闻里看到：大型集会（一个地区短期内传播加强）、自然灾害（一个地区的医疗和
检测短期瘫痪）、谣言（信任下降）、科研突破（进行中的研究缩短）、紧急拨款（预算增加）、自发变异（变异点增加）。
季节不是事件：温带和寒带的冬天飞沫传播更强、夏天蚊媒更强，南北半球相位相反。
遭了灾的地区，逃难的人沿陆路往外走：灾害期间从那里出去的陆路出行是平时的两倍半。

**日程**是每年固定日子到来、提前就知道的事，双方都在“日程”面板里看得到倒计时：

| 日程         | 什么时候                   | 改变什么                                                         |
| ------------ | -------------------------- | ---------------------------------------------------------------- |
| 年初的返乡潮 | 一月下旬起三周多           | 各条路线（陆、空、海）的出行多四成                               |
| 雨季         | 六月中到八月底             | 热带地区的水源、蚊媒传播强两成半                                 |
| 暑期出行     | 七月中起一个月             | 各条路线的出行多两成半                                           |
| 国际赛事     | 七月下旬起两周多，提前一月 | 主办地（经济最大的十二个地区轮着来）有一场集会，航线的出行多两成 |
| 年末假期     | 十二月中旬起三周           | 各条路线的出行多三成                                             |

别的日程提前两周预告。和随机的事件不同，这些是能提前准备的：守方可以赶在高峰前管住口子，攻方可以把
“激增”留到这时候。什么时候开始只看日期，不占模拟的状态。头两章没有日程。
规则在 `sim/src/rules/calendar.ts`，表在 `content/src/tables/calendar.ts`。

**抉择**：隔一阵子，某一方会碰上一件要它拿主意的事——两个选项，各有得失，限几天之内选；到期没选按第一个
（“照旧”的那个）办。守方的例子：带条件的援助（钱马上到，信任掉一点）、要不要公布全部数据、试验里出了不良
反应是硬推还是复核、长假要不要劝阻出行；攻方的例子：押注一个更会传人的分支、藏进动物宿主、趁一场超级传播
而上。选项的得失有立刻生效的（预算、变异点、信任、研究进度），也有持续一阵子的**临时修正**（发现率、传播、
守方的收入、接种速度）——攻方的“蛰伏”走的也是这一套。守方的决定是公开的，攻方那边的事只有攻方知道。头两章不出抉择。

**危机**是另一种来路的抉择：不靠运气，局面到了某个地步才出，而且多半冲着某一个地区——卡片上写着是哪里，
点一下地图飞过去。选项除了上面那些得失，还可以带落在那个地区的效果。

| 危机                 | 什么时候出                                     | 选项                                                                                             |
| -------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 医院挤满了（守方）   | 一个上报过的地区医疗被挤兑到头                 | 让当地自己扛（信任掉）；建临时病房（花钱，那里一个月里救回来的多）；从别处抽调人手（收入少一截） |
| 封得太久了（守方）   | 一个地区的封锁（中档以上）连着开了四十天       | 不让步（那里闹事二十五天，措施的配合只剩六成半）；放松一档；发补贴                               |
| 不肯打的人（守方）   | 疫苗开打时信任不到六成                         | 随他们去（接种慢三成）；请信得过的人出面（花钱）；强制接种（快，伤信任）                         |
| 它们认出你了（攻方） | 守方做完病原鉴定，一局一次                     | 照旧（多攒一点点数）；收敛一阵（更难发现，传得慢）；趁检测没铺开抢着传                           |
| 关不住的口子（攻方） | 一个有感染的地区口岸、机场或港口连着关了三十天 | 不去管它；顺着小路出去（那里的口子一个月里只剩五成半的效果，只有攻方看得到）                     |

同一种危机至少隔四十五天才再出；一方同时成立好几件时，表里靠前的先出；和平时的抉择共用“一方同时只有一件、
两件之间隔两周”。闹事、医疗支援在地图和地区面板上双方都看得到。电脑对手照样会碰上、会选。头两章不出危机。
规则在 `sim/src/rules/crises.ts`，表在 `content/src/tables/decisions.ts`。

## 短期任务

每一方手里同时有一件“接下来这段时间做到什么”的小目标：攻方的例子是再波及三个地区、让累计感染翻三倍、
进入一个高收入地区；守方的例子是再完成一项研究、三十天里新上报病例的地区不超过两个、把上报的病例压下三成、
信任一直保持在六成以上。做到了有一点奖励（变异点，或者预算和信任），没做到不罚；一件完了隔几天发下一件。
任务看的是这一方自己看得到的数——守方的任务按上报的算。目标都写成和局面大小无关的样子，开局和后期都发得出去。
任务表在 `content/src/tables/tasks.ts`，判定在 `sim/src/rules/tasks.ts`。头两章不发任务。

| ---------------------------- | ---------------- | ------------------------ |
| 各地区的感染                 | 真实             | 只有上报的病例和死亡     |
| 对手的措施、应急队和研究进度 | 看得到（公开的） | ——                       |
| 对手的性状                   | ——               | 病原鉴定完成后才看得到   |
| 起源地                       | 知道             | 溯源完成后才知道         |

## 每一局不一样的地方

**世界条件**：普通对局开局时按种子抽两条，一条对攻方有利、一条对守方有利（说的不是同一件事），整局不变，
双方都在“这一局的世界”里看得到。每一条是在默认规则上改几个数：

| 对攻方有利                             | 对守方有利                               |
| -------------------------------------- | ---------------------------------------- |
| 航线繁忙（航线出行多三成半）           | 航线冷清（航线出行少三成）               |
| 财政紧缩（守方每天的预算少近两成）     | 捐助到位（守方开局多 30 预算）           |
| 余波未平（信任从低处起步）             | 信得过的声音（信任高，恢复快）           |
| 冷冬热夏（季节对飞沫传播的影响更大）   | 温和的季节（影响小一半）                 |
| 人心思动（封锁更伤信任，更快有人闹事） | 警觉的诊所（头一簇病例少一半就认得出来） |
| 不安分的基因组（变异点自己涨得更快）   | 后备队（多一支应急队）                   |

开局设置里可以关掉；章节没有（章节的条件是它自己定的）。条件只改界面不直接显示的数。
表在 `content/src/tables/conditions.ts`。

**电脑的性格**：同一个难度下，电脑对手每局按种子有一种打法的偏向，对手面板上写着。
攻方：按部就班（先铺开后致命）、快攻（全力铺开，早早转去致命）、潜伏（看重隐蔽，铺得很开才动手）、
凶猛（很早就往致命走）。守方：按部就班、谨慎（病例还很少就设防，手里多留钱）、
重科研（钱先给研究，设防来得晚）、惜经济（口子照关，封锁能不开就不开）。在 `sim/src/ai/`。

## 章节

五章对应诗的五句，每章是一个限定了条件和目标的剧本，也是教学的顺序：

1. **迷惘**（不盈一握之迷惘）——起源：一个地区里的几个病例。学会看地图、时间、潜伏与发现。
2. **邪念**（由此孕育出邪念）——变异：变异点与性状；守方学病原鉴定与研究。
3. **旷野**（爬过旷野）——陆路扩散：气候、密度、相邻地区；守方学口岸、隔离、地区措施。
4. **山丘**（翻越山丘）——越过防线：富裕地区的医疗、封锁与信任的代价；攻方学耐受与耐药。
5. **长空**（播撒灾厄于长空）——航线与海运、全球的终局、疫苗竞赛。

每章都可以扮演任意一方：攻方在期限内把这一章的目标全做到就赢（结局的原因是“goal”），到期没做到算守方守住了（“held”）；
病原体被清除照旧是守方赢。目标是模拟里的规则（配置里的 `scenario`），所以存档、回放、联机对章节都照常。

| 章   | 病原体     | 条件                             | 攻方的目标                        | 期限    |
| ---- | ---------- | -------------------------------- | --------------------------------- | ------- |
| 迷惘 | 新发病原体 | 只有陆路；没有应急队、抉择、任务 | 累计感染 1300 人次                | 150 天  |
| 邪念 | 新发病原体 | 只有陆路；没有应急队、抉择、任务 | 换到 4 个性状，累计感染 3000 人次 | 240 天  |

守方看到的目标进度是按上报算的，不泄露真实的感染数。教学提示在客户端（`client/src/chapters/hints.ts`）：
每句话有出现的条件，一局里只讲一次，一次只讲一句。

## 结算

一局结束时给出：胜负与原因、天数、累计感染与死亡、波及地区、守方的经济损失与最终信任，以及整局可以回放的时间线。

另有一份**回顾**（`sim/src/rules/review.ts`）：

- **评价**：一个等级（S、A、B、C、D）和它是怎么加出来的。攻方看赢没赢、赢得多快（没赢看推进了多少）、铺得多开；
  守方看赢没赢、离灾厄线多远、信任、保住的经济（没守住看撑了多久）；双方都算做到的短期任务。满分一百。
- **实际发生的**：守方平时只看得到上报的数，结束之后把真实的累计感染、死亡、波及的地区告诉它。
- **大事记**：这一局数得过来的要紧时刻，按先后——每一次变异和退化、每一项研究、双方的每一个抉择、用过的技能、
  第一例死亡、波及第 10 / 50 / 100 / 150 个地区、灾厄线过了几成。对局中各方只在新闻里看得到自己该知道的，
  分出胜负之后整份对双方公开。
