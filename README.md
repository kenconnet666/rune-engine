# rune-engine

用 TypeScript 写的浏览器游戏引擎，和用它做的第一个游戏《迷惘》。个人学习与娱乐项目，MIT 协议。

> 不盈一握之迷惘，由此孕育出邪念，爬过旷野，翻越山丘，播撒灾厄于长空。

《迷惘》是一个关于传染病怎样传播、又怎样被拦住的策略游戏：可以扮演攻方（病原体）或守方（防控），
一个人玩时另一方由电脑控制，也可以两个人各执一方。现在是架构验证阶段——人口、航线、传播参数都是占位数。

## 只面向最新的正式版 Chrome

渲染用 WebGPU，放在 Worker 里画（OffscreenCanvas）。不做旧浏览器的兼容，也不转旧语法。

## 结构

```
packages/            引擎，不知道任何具体游戏
  core               模拟内核：确定性的随机数与数学、时钟、命令与回放、状态哈希、Decimal 与日历日期
  net                主机与会话：主机持有唯一的真实状态，各方发命令、收自己能看到的部分
  render             WebGPU 2D 渲染（不碰 DOM）
  runtime            把线程接起来：消息通道、画布尺寸、主机的计时循环、对局记录的暂存
  ui                 游戏用的界面组件（TSX 编译与样式引擎用 vue-tsx-pro 的）
  assets-build       构建时的素材处理：地理数据 → 地区网格
games/miwang/        《迷惘》
  sim                规则，只依赖 core：浏览器、Worker、Node 里算出逐位相同的结果
  content            数据：世界地图的地区、开局配置
  client             浏览器客户端：主线程是界面，主机和渲染各在一个 Worker 里
```

包之间只能从下往上依赖，`pnpm check:boundaries` 会检查；它还检查模拟相关的包里没有用
`Math.sin`、`Math.exp`、`Date.now` 这类在不同引擎或不同时刻结果不一样的东西。

## 开发

需要 Node 24 和 pnpm（版本见 package.json 的 packageManager）。

```bash
pnpm install
pnpm dev          # 《迷惘》的开发服务器：http://localhost:5180
pnpm check        # 格式、lint、边界、类型、测试
```

改代码时页面怎么反应：

- 界面组件和样式：热更新，游戏不停；
- 模拟的规则：页面刷新，然后照着暂存的对局记录重放到刚才那一步接着走——同一局在新规则下会走成什么样，立刻看得到。

## 两个人玩

主人点“邀请另一位玩家”，把给出的地址在**同一个浏览器的另一个标签页**里打开。
现在走的是浏览器的广播通道，只能连本机；经网络直连（WebRTC）还没做，会话协议不用变。
